TOOLS/SCRIPTS
- Overview sheets (timestamp overlay = compilation seconds, 1 fps, 4x3 tiles, 12 s per sheet):
    /home/franescob/Gaming/research/sheet.sh <video> <start_s> <end_s> <name>
  -> /home/franescob/Gaming/research/sheets/<name>_NN.jpg   (view with Read)
- Detail sheets around the death (4 fps, 2x2 tiles at 854px, label = compilation time*100, e.g. 1675 = 16.75 s):
    ffmpeg -hide_banner -loglevel error -y -ss <S> -t <DUR> -i <video> -vf "fps=4,scale=854:-2,drawtext=text='%{eif\:t*100+<S*100>\:d}':x=4:y=4:fontsize=18:fontcolor=yellow:box=1:boxcolor=black@0.7,tile=2x2:padding=2" -q:v 3 /home/franescob/Gaming/research/sheets/<name>_det_%02d.jpg
  (replace <S*100> with the start time times 100 as an integer)
- To read small text (chat/death message), crop and upscale one frame, e.g.
    ffmpeg -y -ss <t> -i <video> -frames:v 1 -vf "crop=854:120:0:330,scale=1708:-1" /home/franescob/Gaming/research/sheets/<name>_chat.jpg
- Save representative frames (1–3 per death) at native res:
    /home/franescob/Gaming/research/frame.sh <video> <t> <NN>_<player>_<a|b|c>_<what>
  -> /home/franescob/Gaming/research/frames/...   (NN = death number, 2 digits)

METHOD PER CHAPTER
1. grep the transcript lines inside the chapter range.
2. Make overview sheets for the whole chapter and view ALL of them. Work out whose POV each segment is
   (stream overlay/webcam, the name in chat, the HUD). Compilations often chain several POVs, e.g. the victim's stream and then a teammate's.
3. Find the death moment (red "Game over!"/"You died!" screen, the "¡Permadeath!" title, or the red chat line
   "El comienzo del sufrimiento infinito de X ha comenzado. ¡HA SIDO PERMABANEADO!" + vanilla death message).
   Make 4 fps detail sheets for the ~8–12 s before the death and ~2 s after. View them.
4. Record: exact death message text (quote it exactly as displayed, English or Spanish), setting (dimension, biome,
   structure, time of day, weather, lighting), mobs present, held item, armor visible, hearts/health at key moments,
   totem use (the totem animation and green/yellow particles), the step-by-step last seconds, and the reaction (webcam, subs).
5. Save 1–3 representative frames per death.
6. If a chapter has NO real death footage (for example only a reaction or only a ban screen), say so clearly. You may then
   try ONE targeted supplementary YouTube video (listed below or found with
   /home/franescob/.local/bin/yt-dlp "ytsearch10:<query>" --flat-playlist --print "%(channel)s | %(duration)s | %(title)s | %(id)s").
   Download ONLY the relevant section, low-res, into /home/franescob/Gaming/research/clips/ :
     yt-dlp --js-runtimes node --remote-components ejs:github --extractor-args "youtube:player_client=android" -f 18 --download-sections "*MM:SS-MM:SS" -o "/home/franescob/Gaming/research/clips/<name>.%(ext)s" <url>
     (360p with audio; for 480p video-only use player_client=web_embedded -f 135). Plain yt-dlp without these args gives HTTP 403.
   Auto-subs: add --write-auto-subs --sub-langs "es.*" --skip-download ; convert with python3 /home/franescob/Gaming/research/vtt2txt.py file.vtt
   Always give the supplementary video's URL + timestamp.
